## 素点一覧の貼り付け登録

点数入力ごとにBotが返信する、全員分が揃った素点一覧をそのまま送ると、1半荘分として登録・精算できます。専用コマンドは不要です。

```text
田中: 40000
佐藤: 30000
鈴木: 20000
高橋: 10000
```

登録先の対戦設定（3人/4人、開始点、順位点など）を使います。精算後の「+50 (+100)」形式は対象外です。名前の未登録・同名・重複、人数・合計点の不正、同点は登録前に案内します。名前を変更している場合は通常入力を利用してください。

点数入力済みの半荘は上書きしません。登録先が複数あって未選択の場合は「入力開始」で選んでから貼り直してください。飛びがある場合は通常入力と同様に飛ばした人の選択を求めます。過去日時を復元する機能ではなく、貼り付けるたびに新しい半荘を登録します（同じ一覧の再送も別の半荘になるため注意）。
